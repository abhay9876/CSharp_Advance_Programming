# CSharp_Advance_Programming

## Description  
This repository is designed to master **advanced C# programming concepts** through practical, real-world implementations and hands-on problem solving.  
It focuses on writing **robust, expressive, and production-ready C# code** by deeply understanding core advanced topics using a **branch-wise learning approach**.

---

## Tech Stack  
- **Language:** C#  
- **Platform:** .NET 8  
- **IDE:** Visual Studio Code  
- **Version Control:** Git & GitHub  

---

## Repository Structure & Branches  

### `regex` Branch  
- Regular Expression fundamentals  
- Pattern matching and validation  
- Email, phone number, and input validation  
- Search, replace, and extraction techniques  
- Real-world text processing problems  

Purpose:  
> To gain strong control over text parsing, validation, and pattern matching using Regular Expressions in real-world applications.

---

### `nunit` Branch  
- Unit testing fundamentals  
- Writing test cases using NUnit  
- Assertions and test lifecycle  
- Parameterized tests  
- Testing edge cases and exception scenarios  

Purpose:  
> To understand how automated unit testing ensures code reliability, correctness, and maintainability in professional C# applications.

---

### `linq-lambda` Branch  
- Lambda expressions  
- LINQ query syntax vs method syntax  
- Filtering, projection, grouping, and aggregation  
- Real-world data processing scenarios  
- Writing clean, readable, and expressive code  

Purpose:  
> To master functional-style programming in C# and efficiently process data collections using LINQ and Lambda expressions.

---

### `exception-handling` Branch  
- Try-catch-finally blocks  
- Built-in vs custom exceptions  
- Exception propagation and stack trace analysis  
- Best practices for error handling  
- Designing fault-tolerant applications  

Purpose:  
> To learn how to handle runtime errors gracefully and build resilient, stable, and debuggable C# applications.

---

## Features  
- Branch-wise structured learning  
- Real-world, scenario-based implementations  
- Focus on clean and maintainable code  
- Industry-relevant C# best practices  
- Interview-oriented examples and exercises  
- Production-level error handling and testing mindset  

---

## Learning Outcome  
- Strong command over advanced C# programming concepts  
- Ability to write clean, expressive, and testable code

- Better debugging and exception handling skills  
- Readiness for real-world and enterprise-level .NET applications
